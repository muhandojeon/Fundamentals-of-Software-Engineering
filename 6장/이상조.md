# 낯선 코드 이해
요즘 느끼는건데 낯선 코드가 어려운 이유는 코드가 이해하기 어렵기 때문인 것 같다. 보는 사람이 이해하기 쉬운 형태로 코드를 짜면 그리 어려울게 없다고 생각함.
이건 작은 함수 단위의 이야기일 수 있고... 전체적인 큰 그림은 책에서 제안한 것처럼 제품의 의도부터 점점 작은 단위로 내려가면서 탑다운으로 파악하는게 좋다고 생각함.
근데 전체적으로 ai 활용을 너무 배제하고 이야기하는 것 같다. 사실 아키텍처건 구조건 뭐건 요샌 ai한테 물어보면 바로 정리해주는데 왜 그런 얘기는 책에 없을까?
차라리 낯선 코드를 쉽게 이해하도록 ai를 어떻게 활용하면 좋을지 알려주는게 더 유익하지 않을까 싶기도 함.
