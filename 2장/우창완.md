# 코드 문해력 = 실무 기본 능력


## 기존 코드 작업의 어려움
코드를 작성하는 시간보다, 코드를 읽는 시간이 길다. ai agent로 더더욱 코드 읽는 시간이 많아지고 있음.
(기능을 만들 때도, ai 가 작성해준 코드를 읽고 이해해야함..)

**해결해야할 문제**
1. 복잡한 도메인
2. 문제를 푸는 다양한 방법/패러다임이 존재
3. 적절한 추상화 수준을 갖추지 못함
4. 기술 부채, workaround


## 인지 편향
코드를 읽을 때, 인지 편향이 작용한다.

* 이케아 효과: 내가 작성한 코드가 더 나아보이는 현상
* 단순 노출 효과: 익숙한 코드, 해결방법에 끌리게 됨, 편협한 시각
