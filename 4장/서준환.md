# 소통을 돕는 적정 모델링



건축과 달리 소프트웨어는 리팩터링될 수 있다.

승준님이 늘 말씀하시던 "소프트웨어가 왜 소프트웨어인줄 아시나요?"가 생각나는 구절이었습니다.



다이어그램은 **정확하다는 가정**하에 새로운 시스템을 접하는 사람들에게 도움이 될 수도 있다.

문서와 동일하게 업데이트 잘 해야겠다.



아직 저는 하수인가봐요. 이런 다이어그램을 통해서 무언가 해보질 않았어요. 하나 해봤다면 머메이드 통해서 api 응답 및 인증 관련하여 순차 다이어그램 그리는 정도?..

그것 외로는 이전에 [omlet](https://marketplace.visualstudio.com/items?itemName=Omlet.omlet-vscode-extension) 이라는 vscode extension을 소개해주셨을 때 보고 이후론 못봤던 것 같아요.



읽으면서 느끼는 건데 정말 최신화가 중요할 것 같아요.
