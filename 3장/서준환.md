## 간결함의 가치



42서울에서 사용하던 [norminette](https://github.com/42school/norminette)가 생각나네요.

대충 설명드리면 그냥 린트 툴과 같고요. 아래의 규칙을 적용합니다.

- **Line limits:** Max 80 characters per line. Max 25 lines per function. Max 5 functions per file.
- **Naming:** Variables and functions must use lowercase with underscores (snake_case). Global variables must start with `g_` and structs with `s_`.
- **Banned features:** No `for`, `do...while`, or `switch` statements. No nested ternary operators.
- **Variable declaration:** Local variables must be declared at the top of a function, separated from the code logic by an empty line.
- **Comments:** Only `/* */` block comments are allowed; C++ style `//` comments are forbidden.



간결한 코드를 작성하기 위해 알게모르게 작업당하고 있었네요.



### 상속보다는 구성

객체지향을 잘 몰라서리,,  지쌤한테 물어보니 아래와 같이 알려주네요!



- **상속**: 부모 클래스의 기능을 물려받는다. → 강하게 결합되어 변경이 어렵다.
- **구성**: 필요한 객체를 내부에 넣어 사용한다. → 쉽게 교체하고 조합할 수 있다.



```
class Car
  def initialize(power_source)
    @power_source = power_source
  end

  def start
    @power_source.start
  end
end
```

전기차에는 전기 모터를 넣고:

```
electric_car = Car.new(ElectricMotor.new)
```

내연기관차에는 가솔린 엔진을 넣습니다.

```
gas_car = Car.new(GasEngine.new)
```

전체 예시는 이렇습니다.

```
class ElectricMotor
  def start
    puts "전기 모터로 출발"
  end
end

class GasEngine
  def start
    puts "가솔린 엔진으로 출발"
  end
end

class Car
  def initialize(power_source)
    @power_source = power_source
  end

  def start
    @power_source.start
  end
end

Car.new(ElectricMotor.new).start
Car.new(GasEngine.new).start
```



한 줄 요약: **“A는 B다”라면 상속, “A는 B를 사용한다”라면 구성. 보통은 더 유연한 구성을 우선 고려한다.**
