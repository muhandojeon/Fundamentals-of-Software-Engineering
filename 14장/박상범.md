# 14장 성공적인 경력 계획과 관리

## 기술 전문가 경로

- 아키텍트 : 조직 전체에 영향을 미치는 상위(핵심) 기술 결정, 시스템 아키텍처 설계, 기술 개념을 비기술 담당자에게 설명하는 강한 소통 능력
- 스태프 엔지니어: 기술 리더, 복잡한 문제 해결, 특정 도메인에 깊은 기술적 전문성 보유

## 리더 경로

- 기술 관리자: 사람, 프로세스, 성과, 구성원의 성장에 집중하며 개발 팀을 이끄는 사람, 기술적 지식은 유지하되 코드 작성 할 일 거의 없음
- 기술 제품 관리자: 사업 요구사항을 기술적 해결책으로 전환, 조적전반의 이해관계자와 긴밀하게 협력, 기술적 이해와 사업 감각이 모두 필요
