# 자동 테스트: 좋은 소프트웨어를 만드는 최고의 습관

내가 생각하는 테스트의 중요한 3가지

- 의미있는 단위의 로직을 검증해야하고
- 작성하기 쉬워야하고
- 피드백 주기가 빨라야한다

테스트는 의미있는 단위의 로직을 검증해야한다. 중요한 로직일 수록 많은 검증이 되어야하고, 이 수단이 자동화 테스트이다.
테스트 작성할 때, 특정 api 가 없고, 로컬 환경에서 테스트로 검증하기 어렵다면 누구도 테스트 작성을 원하지 않고, 작성 경험이 매우 안좋게 된다.
자동화 테스트는 수동 테스트보다 검증 리소스를 줄이고 빠른 피드백 루프를 위해 사용된다.
