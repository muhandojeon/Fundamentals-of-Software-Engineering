# 7장: 엔지니어라면 꼭 알아야 할 UI 설계 기초

좋은 UI 설계의 출발은 UX가 설정한 목표를 달성하는 것이다.  

접근성, 지역화, 국제화를 처음부터 염두에 두고 앱을 만드는 편이 쉽다.  

### 사용성

사용성은 '사용자가 이 애플리케이션을 얼마나 쉽게 사용할 수 있는가'로 요약된다.  
다음과 같은 품질 요소로 사용성이 정의된다.

- **학습 용이성**: 인터페이스를 배우기 얼마나 쉬운가, 도움말과 문서가 있는가
- **효율성**: 사용자가 얼마나 효율적으로 작업할 수 있는가, 클릭 횟수 최소화
- **기억 용이성**: 인터페이스가 얼마나 기억하기 쉬운가, 한동안 쓰지 않다가 다시 써도 금방 익숙해지는가, 매번 처음부터 다시 배우는 기분이 드는가
- **발견 용이성**: 기능을 파악하기 얼마나 쉬운가, 핵심 기능조차 숨어 있는가
- **오류 처리**: 오류를 처리하고 복구하는 방식, 힌트, 유효성 검사, 입력값 서식, 시각적 단서 등으로 오류를 미리 방지하는가
- **사용자 만족도**: 사용한 후 사용자의 기분은 어떤가
- **접근성**: 보조 수단을 지원하는가

### 접근성

사용성이 모든 사용자의 편의성과 만족도에 집중한다면,  
접근성은 사용 능력이 달라도 소프트웨어를 사용할 수 있게 만드는 데 집중한다. (시각적 제약, 청각적 제약, 기동성 제약, 인지적 제약)

### 국제화와 지역화

혼용해서 쓰기도 하지만 관련되면서도 구분되는 개념이다.

- 국제화: 다양한 언어와 문화적 기대치에 적응할 수 있도록 설계 및 구축하는 과정
- 지역화: 인터페이스를 특정 시장의 문화와 언어에 맞게 조정하는 과정

> 이 부분은 경험이 없어서 아쉽네요 글로벌 서비스도 한 번쯤 개발해 보고 싶어요

### 사용자 파악

개발자는 사용자가 아니다.  
사용자를 이해하는 데 며칠만 투자해도 사용자에게 감동을 주는 앱과 혐오감을 주는 앱의 차이를 만들어낼 수 있다.  
낮은 사용성은 사용자의 업무에 직접적인 영향을 줄뿐만 아니라 실제 비용 손실로 이어진다.  

### 사용성 극대화

사용성의 여러 요소 중 어디에 집중해야 할까?  
**모든 요소 극대화 대신, 이 애플리케이션이 어떻게 사용될 것인지 질문**
- 매일 종일 쓰이는 애플리케이션: 효율성, 기억 용이성, 만족도가 중요, 매일 쓰면 자연스럽게 기억에 남으므로 배우기 어렵거나 발견하기 힘든 상호작용이 섞여 있어도 어느 정도 용인이 된다.  
- 가끔 쓰이는 애플리케이션: 기억 용이성 < 학습 용이성, 발견 용이성 
- CAD 소프트웨어처럼 태생적으로 복잡한 애플리케이션: 사용자가 별도의 교육을 받거나 반복 숙달을 통해 인터페이스 익힘
- 차세대 소셜 네트워크: 공부하며 앱을 쓰지 않을 것이기 때문에 학습 용이성과 발견 용이성이 핵심
- 퍼즐 게임: 과정 자체가 재미이기 때문에 일부러 발견 용이성 낮게 설계

> 저는 리크루터가 매일 쓰는 서비스를 만들고 있으니 효율성, 기억 용이성, 만족도가 중요하겠네요  
> AI로 개발 속도를 올리는 것도 의미가 있지만, 사용자가 적응하기도 전에 화면과 기능이 계속 바뀌는 상황은 경계할 필요가 있다는 생각이 들어요

### 디자인 원칙

- 대비: 사용자가 명확하게 구분할 수 있을 정도로 명확히 달라야 한다.
- 반복: 친숙함, 통일감 제공, 시각적 단위 생성
- 정렬: 깔끔하고 세련된 느낌
- 근접성: 항목들이 함께 묶이면 본능적으로 하나의 시각적 단위로 보게 된다. 항목들 간에 어떤 유사성이 있음을 느낀다.

### 올바른 것을 명확하게 만들기

상호작용이 획기적으로 더 나은 경우가 아니라면 뻔한 방식을 고수하는 것이 최선이다.

### 좋은 오류 메시지의 중요성

좋은 오류 메시지는 이슈를 디버깅하고 해결하는 데도 도움을 준다.  
사용자에게 맥락을 제공하는 것 외에도, 사용자가 실수를 만회할 수 있게 해야 한다. ex. 실행 취소, 되돌리기 버튼

> 어드민 에러 메시지는 제가 직접 작성하는데, 가끔 도움이 필요할 땐 AI한테 물어봅니다  
> [better-writing](https://github.com/jakubkrehel/skills/blob/main/skills/better-writing/SKILL.md)이라는 스킬이 있긴 한데, 그냥 물어봐도 상황에 맞게 잘 써주는 것 같아요
